# WebUI-Markenassets

`reakt-logo.svg` ist das offizielle, oeffentlich bereitgestellte REAKT-Logo
aus dem DATIpilot-Projektauftritt:

`https://prev.neueshandeln.de/bmbf/dati/img/-logo/Logo_reakt_schwarz.svg`

Die ReAKT-Themefarben stammen aus der aktuell ausgelieferten Konfiguration
von `https://www.reaktsh.de/`:

- Dunkelblau: `#1c3647`
- Gruen: `#82fa8c`
- Indigo: `#5750fe`
- Flieder: `#cdc3ff`

Logo und Name bleiben Eigentum der jeweiligen Rechteinhaber und werden hier
nur fuer die angeforderte Projektkennzeichnung verwendet.
