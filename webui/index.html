ReaktRailAi

Entstehungsgeschichte

ReaktRailAi entstand im Rahmen des REAKTOR-Projekts innerhalb der REAKT-Initiative. Ziel ist es, stillgelegte eingleisige Strecken mithilfe autonomer Schienenfahrzeuge wieder nutzbar zu machen. Die Fahrzeuge sollen sich unterwegs miteinander kuppeln können, sodass Fahrgäste zwischen ihnen wechseln können. Dadurch soll auf eingleisigen Strecken Personenverkehr in beide Richtungen gleichzeitig ermöglicht werden.

Für einen wirtschaftlichen Betrieb müssen die Schienenfahrzeuge autonom fahren können. Damit sie während der Fahrt Kollisionen vermeiden, benötigen sie eine automatische Hinderniserkennung. Ein erster Ansatz dafür wurde im Rahmen einer Bachelorarbeit im Kontext der REAKT-Initiative entwickelt. In einem anschließenden Masterprojekt wurde das System weiterentwickelt und für eine anschauliche Demonstration aufbereitet. Das Ergebnis kann auf dieser Seite betrachtet werden.

So funktioniert ReaktRailAi

Die hier eingesetzte KI-Pipeline basiert im Kern auf einem YOLO26m-Modell, das auf einem NVIDIA Jetson Orin NX mit 16 GB Arbeitsspeicher ausgeführt wird. Als Eingabe erhält das System ausschließlich den Videostream einer einzelnen Kamera an der Fahrzeugfront. Das Kamerabild wird über das Netzwerk an den Jetson übertragen und dort vom KI-Modell verarbeitet.

Das Modell erkennt gleichzeitig den Gleisbereich und sichtbare Objekte, die im Training vorkamen oder den gelernten Merkmalen ähneln. Der Prozentwert neben einem Objekt gibt an, wie sicher das Modell ist, dass das Objekt zur angezeigten Klasse gehört. Anschließend wird geometrisch geprüft, ob sich ein erkanntes Objekt innerhalb der Fahrspur oder daneben befindet.

Damit das System auch auf unbekannte Objekte reagieren kann, lässt sich zusätzlich die Gleismaske auf Auffälligkeiten untersuchen. Fehlt innerhalb eines ansonsten zusammenhängend erkannten Gleisbereichs plötzlich ein Teil der Maske, kann dies auf eine Verdeckung und damit auf ein mögliches Hindernis hinweisen. Aus diesen Auswertungen kann später beispielsweise abgeleitet werden, ob eine autonome Bremsung erforderlich ist.

Grenzen des Systems

Eine wesentliche Einschränkung ist, dass ausschließlich auf Sicht gefahren werden kann. Der Bremsweg darf deshalb niemals länger als der einsehbare Streckenabschnitt sein. Zudem fehlt derzeit eine unabhängige Redundanz, beispielsweise eine lidarbasierte Hinderniserkennung, mit der sich die Ergebnisse zusätzlich absichern ließen.

Auch Witterung und Lichtverhältnisse können die Erkennung beeinträchtigen. Das gilt insbesondere bei Regen, Nebel, Schnee, Dunkelheit oder tief stehender Sonne, wenn die Sicht der Kamera eingeschränkt ist.

Vorteile des Ansatzes

Der größte Vorteil sind die vergleichsweise geringen Hardwarekosten, da das System mit einer Kamera und einer kompakten Recheneinheit auskommt. Gleichzeitig liefert das Kamerabild viele Informationen: Das Modell kann nicht nur ein Hindernis erkennen, sondern auch dessen Objektklasse bestimmen.

Der Ansatz lässt sich außerdem vergleichsweise einfach nachrüsten, durch Softwareupdates erweitern und anhand aufgezeichneter Videos nachvollziehen. Diese Aufnahmen können zugleich genutzt werden, um das Modell gezielt zu prüfen und weiterzuentwickeln.
